# 爱赛思高性能计算

用于爱赛思「科研工作台 → 高性能计算」，入口为 <https://ai4s.yicloud.com/workflow/task>。高性能计算（high-performance computing，HPC）指使用计算集群运行任务；`HPC` 和 `MHPC` 在本平台也是具体分区名称，应保持原样。

每位用户使用自己的账号、项目和资源。平台权限、分区、软件版本和接口以当前可见页面、程序帮助及对应版本手册为准；本技能不附带账号配置，也不证明当前用户环境已经登录、提交或完成计算。[来源与适用范围](references/sources.md)说明了接口来源和验证限制。

## 定位账号、项目和入口

复用当前对话、已有会话和用户自己的项目记录。爱赛思与 Inspire/启智是不同平台，不能互用项目标识、工作空间、镜像、接口或命令。只有现有信息确实不能判断平台时，询问缺失信息。

优先复用已有有效登录会话：

- `scripts/aisaisi_cli.py` 使用正常平台接口查询项目、实例和作业，通过 WebSocket（双向实时通信协议）执行远端命令。已有会话时不重新登录、不逐次操作浏览器；用法见[本地命令行客户端](references/cli.md)。
- `scripts/aisaisi_upload.py` 复用同一显式会话，上传前检查同名文件，上传后核对文件名和长度。使用独立任务目录，避免并发写入同名文件；用法见客户端说明。
- 浏览器中选择用户已加入的高性能计算项目，使用现有 WebSSH（浏览器中的命令行终端）实例；见[访问、实例和文件](references/access-and-files.md)。
- 直接 SSH（Secure Shell，安全外壳连接）只复用已有且确认可用的入口。WebSSH 可连接不代表平台提供直接 SSH 端口。
- `scripts/aisaisi_slurm.py` 生成单节点 Slurm（集群作业调度系统）脚本，也支持已有 SSH 别名；见[工具用法](references/helper.md)。没有直接 SSH 时，通过平台客户端提交生成的脚本。

密码或验证码只在本地交互终端输入。访问令牌（access token，用于证明已登录的凭据）只从用户指定的私有会话文件或环境变量读取，不搜索浏览器存储。会话文件放在代码仓库之外；不分享带认证信息的终端地址。

先查询当前账号的项目映射，再显式使用数值项目编号；不以项目显示名、前端常量、示例账号或其他用户的目录推断权限。客户端不会自动创建、续期或释放实例。

## 按任务选择路径

| 任务 | 操作路径与说明 |
| --- | --- |
| 查询作业、排队原因、历史或日志 | [Slurm 作业提交与观察](references/slurm.md) |
| 普通 CPU（中央处理器）或 GPU（图形处理器）计算 | 当前允许的 `HPC` 分区；提交实际程序入口 |
| LogicMD 分子动力学（molecular dynamics，MD） | 模板作业或 `MHPC` 分区；见 [LogicMD 与 MHPC](references/logicmd.md) |
| 续算、拓扑（topology，原子及其相互作用的定义）或轨迹（trajectory，按时间记录的体系状态）合并 | 按原程序及版本处理；见 LogicMD 说明 |
| 登录、查询、上传和命令行提交 | [本地命令行客户端](references/cli.md) |
| 下载、连接或释放实例 | [访问、实例和文件](references/access-and-files.md) |

平台手册将 `MHPC` 定义为 LogicMD 专用分区；遵守当前平台规则，不在那里运行其他仿真软件、模型训练或普通数据处理。准备和后处理使用平台允许的环境。LogicMD 版本须与 `md.ctl` 及续算文件匹配，本技能不定义其字段格式。

思朗专用资源与普通 NVIDIA GPU 分别处理；通用资源字段（generic resources，GRES）须从当前调度配置确认，不能据字段名称推断芯片型号或数量。迁移恒 pH 分子动力学（constant-pH molecular dynamics，CpHMD）时，先确认对应程序、版本和方法支持；结构与拓扑格式兼容不等于算法兼容，固定质子化模拟不能替代原方法验证。

## 执行与提交

查询状态只读取能回答当前问题的信息。提交计算前合并一次必要检查：

1. 账号、项目、程序和输入明确；程序入口存在，输入可解析。
2. 本次工作目录和输出路径明确，保留已有结果和唯一副本。
3. 分区、软件环境、CPU、GPU、内存和时限符合用户已授权的范围；浏览器实例规格与计算作业规格分别确认。
4. 复用适合当前程序、输入和环境的小规模成功记录；缺少时进行一次必要的小规模试运行。
5. 用户封存的数据与正式测试集保持封存。

满足后直接提交，复用已有授权。页面「信息确认」属于操作步骤，核对后完成，不转换成重复索要许可。取消和删除仅限用户已授权的对象或本任务明确的一次性资源。

普通 `HPC` 作业按实际需求申请，不默认使用 `--exclusive`（独占节点资源）。当前分区强制独占时，确认整节点申请仍在已授权上限内。提交失败只处理真实错误；超时或连接中断导致结果不明时，先查询同名作业、提交时间和工作目录，避免重复提交。

在授权范围内，可增大批量大小（batch size，一次处理的样本数）或并行处理独立样本；不擅自改变模型、数值精度、数据划分和确定的训练设置。不做 SHA 哈希校验（计算文件摘要）、冗余实验或多轮重复检查。

## 项目记录与结果报告

长期接入时可在用户自己的项目中维护 `AISAISI.md`，仅记录已确认的平台地址、项目、现有连接别名、持久目录、程序入口、软件版本和资源上限。不写入秘密信息、临时连接地址或原始日志，不把私人记录提交到本技能的公共仓库。一次性查询不要求创建记录。

报告分别说明脚本已准备、已获得作业编号、平台排队、程序开始、程序完成和输出检查结果。训练任务再分别说明训练开始、训练完成、验证集指标与封存测试集结果。`COMPLETED`（调度系统记录作业完成）及格式检查成功不自动证明科学结果正确。作业离开当前队列后查看历史和日志。

报错后只修复直接原因并检查受影响部分。部分样本失败时保留错误，用完整成功样本继续符合既定门槛的后续步骤，报告成功率及最终样本数。无新错误或状态变化时不重复生成检查报告。
