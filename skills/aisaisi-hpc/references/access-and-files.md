# 访问、实例与文件

以下流程参考《智爱赛思平台-高性能计算-使用说明》V1.0 的 §3.1、§3.2.4、§3.3、§3.4。手册不随仓库分发，从平台「手册」菜单获取；当前账号页面决定实际权限、实例规格和数量限制。

## 进入项目

复用已有登录状态，在项目切换区域选择用户确认的高性能计算项目，再进入「高性能计算」。名称相同的项目须按数值编号和成员资格区分。没有菜单时检查当前项目及成员资格，不擅自改到其他可见项目。

需要管理员邀请或使用者登录时说明缺少的入口。客户端支持正常登录，不搜索浏览器凭据、不代为注册，也不猜测密码。

浏览器操作依据当前可见按钮、字段和提示；不假定页面地址和元素一直不变。网页终端输出无法从页面文本读取时查看终端图像，不凭按钮点击判断命令已执行。

## 连接实例

从「实例」列表连接已有 WebSSH（浏览器中的命令行终端）或 VNC（Virtual Network Computing，远程图形桌面）实例。「作业 → 创建终端作业」也可进入终端相关流程。

优先复用已就绪实例。确需创建时，以当前页面允许的 CPU（中央处理器）、内存和自动释放时间为准，在已授权资源范围内完成信息确认。等实例进入可连接状态后再连接。实例规格、自动释放时间与计算作业资源、时限分别记录。

直接 SSH（Secure Shell，安全外壳连接）只用于已有且确认可用的入口；网页终端地址和内部节点名不能当作公网直连地址。身份验证或主机验证失败时保留具体错误，按既有连接流程修复，不关闭主机验证。

## 文件与工作目录

先查看文件页面的当前目录。计算节点持久目录从终端 `pwd`、文件页面和用户自己的项目记录确认；不要套用他人的路径。

每次计算在持久空间使用独立目录，放入实际程序、控制文件、结构、拓扑（topology，原子及其相互作用的定义）和其他输入。文件页面路径可能相对于个人空间根目录；上传接口路径与计算节点绝对路径的映射需要在当前账号中确认。

- 上传：选定目录，等待上传完成，再确认文件名与大小。命令行上传见[客户端说明](cli.md)。
- 下载：选定明确文件或文件夹，等待打包与下载完成，确认本地文件已生成。
- 重命名：确认当前任务没有按旧路径引用该文件。
- 删除：只处理已授权的明确对象，保留实验结果、检查点和唯一副本。

大型传输按需确认目标容量。已有直接 SSH 入口可用 `scp`（安全文件复制）或 `sftp`（安全文件传输协议），不在命令中传密码或令牌。客户端没有实现文件下载，不因下载按钮可见而报告下载完成。

## 释放实例

删除前确认所需文件已写入持久空间，没有本任务依赖的进程；未保存文件可能随实例释放丢失。只清理用户授权或本次明确的一次性实例，完成后查看实际状态。实例释放不能用来推断计算作业是否继续。
